# Portfolio — Santiago Natalichio Bestosini

Sitio personal de una página: quién soy, qué construí y cómo contactarme.

**Stack:** Next.js 16 (App Router), React 19, TypeScript y Tailwind CSS v4. Estático de punta a punta: sin backend, base de datos ni analítica.

El código está en [`portfolio/`](portfolio/), con su propio [README](portfolio/README.md) (cómo se corre y cómo está organizado), el brief de producto en [`PRODUCT.md`](portfolio/PRODUCT.md) y el sistema visual en [`DESIGN.md`](portfolio/DESIGN.md).

```bash
cd portfolio
pnpm install
pnpm dev      # http://localhost:3000
```
